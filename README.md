# 水平対流と海底地形：海嶺は深層循環をどう塞ぐか

熱流体力学演習 2026 最終プロジェクト（Oceananigans.jl による水平対流）

> 状態：計画段階（2026-11-13 テーマ登録）。11/27 の計画フィードバックまでに詳細を確定する。

## 問い

海面だけを加熱・冷却したときにできる循環（水平対流：海洋深層循環の最も単純なモデル）について，

1. **Rayleigh 数を変えると**，循環の強さと浮力輸送（Nusselt 数）はどう変わり，スケーリング則 Nu ∝ Ra^(1/5) に従うか．
2. **海底に山（海嶺）を置き，その高さだけを変えると**，深層の循環はどこで塞がれ，循環強度と浮力輸送はどう変わるか．

### 仮説（計算前の予想）

- Ra を下げると表面境界層が厚くなり，Nu と循環強度 Ψ は小さくなる．Ra を 1/10 にすると Nu は約 10^(-1/5) ≈ 0.63 倍．
- 山が低いうちは Ψ も Nu もほとんど変わらない．山がある高さを超えると深層が山の両側で分断され，冷たい水が片側の盆地に溜まって Ψ が急に弱まる．Nu は Ψ ほど変わらない．

### 用途

- 海洋の深層循環（高緯度で冷えた水が沈み，低緯度で温まる）と，大西洋中央海嶺やデンマーク海峡のような海底地形による深層水の制限の理解．
- 上から不均一に加熱されるガラス溶解炉，片側だけ日が当たる湖・貯水池など，同じ型の流れ．

## 未知量と無次元化

| 量 | 意味 | 基準 |
|---|---|---|
| u = (u, w) | 速度（x 水平，z 鉛直上向き） | U⋆ = √(Lx b⋆) |
| p | 動圧（kinematic pressure） | |
| b | 浮力 | b⋆ |

基準値 b⋆ = 1，H = 1，Lx = 2H．時間は t* = t √(b⋆/Lx)．

## 方程式（2 次元，非回転，Boussinesq 近似）

- 運動量：∂t u + (u·∇)u = −∇p + b ẑ + ν∇²u
- 連続：∇·u = 0
- 浮力：∂t b + u·∇b = κ∇²b

Ra = b⋆ Lx³ / (νκ)，Pr = ν/κ．Ra を変えるときは Pr を固定し，ν = √(Pr b⋆ Lx³ / Ra)，κ = √(b⋆ Lx³ / (Pr Ra)) で両方を変える．

## 領域・格子

- 領域 x ∈ [−Lx/2, Lx/2]，z ∈ [−H, 0]
- 格子 128 × 64（`RectilinearGrid`，x は Bounded，y は Flat）．CI 用の小格子は 64 × 32．
- 海嶺：中央にガウス型の山 z_b(x) = −H + h exp(−x²/(2σ²))．`ImmersedBoundaryGrid(grid, GridFittedBottom(z_b))` で表現する（公式ギャラリーの「Internal tide by a seamount」例と同じ方式）．h/H = 0, 0.25, 0.5, 0.75．σ は計画FBまでに決める．

## 初期条件・境界条件

- 初期：u = w = b = 0
- 上面浮力：b(x, 0) = −b⋆ cos(2πx/Lx)
- 他の浮力境界（側面・底面・山の表面）：zero-flux
- 速度：全境界で不透過かつ free-slip

## 数値計算

- `NonhydrostaticModel` + `BuoyancyTracer`，5 次 WENO，3 段 Runge–Kutta
- 時間刻み：初期 0.01，`conjure_time_step_wizard!` で CFL 0.7，max Δt = 0.1
- 終了 t = 40（平均窓が統計的定常にあるか確認し，足りなければ延長），0.5 ごとに JLD2 保存
- 版：Oceananigans v0.110.15（commit 5e62a72），Julia は Oceananigans の compat に合う版を `Project.toml` / `Manifest.toml` で固定

## 測る量

| 指標 | 定義 |
|---|---|
| Nu(t) | ⟨κ|∇b|²⟩ / χ_diff（χ_diff は流れがない純拡散状態の値） |
| Ψ | max|ψ| / (Lx U⋆)，u = ∂zψ，w = −∂xψ |
| K | 領域平均運動エネルギー / (Lx b⋆) |
| δχ/H | 浮力散逸 χ の鉛直重心による境界層厚さ |
| 海嶺の指標 | 山の両側の深層平均浮力差，山頂を越える流量 |
| 費用 | 初回コンパイルと 2 回目の実行時間，ステップ数，メモリ，JLD2 容量，スレッド数 |

瞬時値と平均値を分け，平均窓 [t0*, t1*] は全条件で揃える．窓を前半・後半に分けて安定性も見る．

## 検証

1. 公式例（Ra = 10^8）の再現
2. 離散発散，浮力分散の収支残差，CFL を半分にしたときの感度
3. 純拡散解 b_diff との比較：格子を細かくすると Nu → 1．山ありでは流れを止めた拡散だけの計算で χ_diff を数値的に作り，h = 0 で解析解と一致することを確認
4. Nu–Ra を Rocha et al. (2020, JFM, doi:10.1017/jfm.2020.269) と比較

## 限界

2 次元・非回転・free-slip・余弦型の上面浮力・Laplacian 拡散という限定条件の結果であり，有限格子と有限平均窓の影響が残る．4 点の Ra から言えるのは傾向で，指数の確定には限界がある．
